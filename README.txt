NAYDE — sito pronto per GitHub Pages

CONTENUTO
- index.html: sito con modulo collegato a Google Apps Script
- assets/nayde-logo.jpg: logo

COME PUBBLICARLO
1. Estrai questo ZIP sul computer.
2. Su GitHub crea un nuovo repository, per esempio nayde-sito.
3. Nel repository scegli Add file > Upload files e carica index.html e la cartella assets nella radice del repository.
4. Premi Commit changes.
5. Vai in Settings > Pages. In Build and deployment scegli Deploy from a branch, branch main e folder /(root), poi Save.
6. Attendi qualche minuto e apri l'indirizzo GitHub Pages mostrato in Settings > Pages.

MODULO CONTATTI
Il modulo è configurato per inviare i campi allo script Google Apps Script e inoltrarli a nayde.office@libero.it. Con la modalità no-cors il browser non può leggere la risposta effettiva di Google: il messaggio del sito non è una ricevuta verificata di consegna. Fai una prova dal sito pubblicato e controlla la posta e le esecuzioni di Apps Script.
